### Quebra de Paradigma

- Muda o funcionamento de uma determinada vertente, quebra de padrões.
- Exemplo: Mudança de cartas para mensagems

### Paradigmas de programação

Imagine que você está numa biblioteca, temos regras espeficas para a organização de livros, o titulo,  o tema...

- Cada paradigma engloba algumas características;
- Uma linguagem pode seguir um ou mais paradigmas;

### Quais são os Principais Paradigmas

- Funcional
- Lógico
- Orientado a objetos
- Imperativo
- Orientado a eventos
- Outros

#### Por que estudá-los?

- Decisão técnica
- Melhorar capacidade de resolver problemas
- Expandir conhecimento da linguagem
